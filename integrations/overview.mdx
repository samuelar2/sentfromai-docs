## Before you connect

If you use **Osmos**, follow the [built-in setup guide](/integrations/osmos). Osmos manages the connection for you; the API-key steps below are for connecting your own SentFromAI workspace to other platforms.

Create or select an inbox in the [SentFromAI console](https://console.sentfrom.ai/inboxes), then create a key on the [API keys page](https://console.sentfrom.ai/keys). Each user connects their own workspace. Agent-created accounts must be claimed before sending is enabled; existing account restrictions and plan limits also apply.

Enter the key only in the platform's protected connection field. Test sending and replies with mailboxes you control. Use a stable Client ID when retrying the same send or reply, and keep both the ID and message content unchanged.

For release updates and source, see [sentfromai/integrations](https://github.com/sentfromai/integrations). For help, email [support@sentfrom.ai](mailto:support@sentfrom.ai) with the platform, step, time, and non-sensitive error text.
